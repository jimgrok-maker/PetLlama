# PetLlama
Android APK to access a remote llama.cpp server over the OpenAI-compatible API.

- Add one or more servers (LAN IP or Tailscale address)
- Auto-fetch model list, streaming chat, local conversation history
- Exposes temperature / top_p / max_tokens / system prompt per conversation
- Built via GitHub Actions — download the APK from Releases, no Android Studio needed
